## Google Forms Setup Instructions

### Creating the Forms

1. **Go to Google Forms:**
   - Visit https://forms.google.com
   - Click "Blank" to create a new form

2. **Title and Description:**
   - Pre-Test: "AI Coding Club - Pre-Test Survey"
   - Post-Test: "AI Coding Club - Post-Test Survey"
   - Add the description provided above

3. **Add Questions:**
   - Copy each question from the templates above
   - Set correct answer types (Multiple choice, Checkboxes, Short answer, Long answer, Linear scale)
   - Mark required questions with red asterisk (*)

4. **Required Questions:**
   - Mark these as required:
     - Pre-Test: Questions 3, 5, 7, 8
     - Post-Test: Questions 1, 2, 3, 4, 5, 6, 9, 10, 12

5. **Form Settings:**
   - Click the gear icon (Settings)
   - Enable "Collect email addresses" (optional)
   - Enable "Limit to 1 response" (optional)
   - Disable "Edit after submit"

6. **Response Destination:**
   - Click "Responses" tab
   - Link to Google Sheets for easy analysis
   - Name the sheet "User Testing Responses - [Date]"

7. **Share the Form:**
   - Click "Send" button
   - Copy the shareable link
   - Send to testers via email or direct message

### Analyzing Responses

#### Google Sheets Formulas for Analysis

**Average ratings (insert in Sheet):**

```
=AVERAGE(D2:D10)  // Average of "Instructions were clear" (assuming column D)
=AVERAGE(E2:E10)  // Average of "AI tips useful" (column E)
=AVERAGE(F2:F10)  // Average of "Motivated to continue" (column F)
```

**Success rate:**

```
=COUNTIF(A2:A10,"Yes, I completed it fully")/COUNTA(A2:A10)*100
// Percentage who completed Level 0.1
```

**Ratings breakdown:**

```
=COUNTIF(D2:D10,">=4")/COUNTA(D2:D10)*100
// Percentage who rated clarity as 4-5/5
```

#### Qualitative Analysis

**Common themes:**
1. Read all open-ended responses
2. Tag responses with themes (e.g., "confusing terminology", "helpful visuals", "too long")
3. Count frequency of each theme
4. Prioritize by frequency and severity

**Example tagging:**
- "I didn't understand what Replit was" → Tag: [terminology]
- "The prompt was too long" → Tag: [cognitive-load]
- "Screenshots would help" → Tag: [visuals-needed]
