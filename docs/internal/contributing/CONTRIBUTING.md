# Contributing to AI Coding Club

Thank you for your interest in contributing to AI Coding Club! 🎉

## 🤝 Ways to Contribute

### 1. Report Issues
Found a bug or have a suggestion?
- Open an [Issue](https://github.com/IsaacZhaoo/aicodingclub/issues)
- Use a clear, descriptive title
- Include steps to reproduce (for bugs)

### 2. Improve Content
Help improve our tutorials and resources:
- Fix typos or grammar
- Clarify confusing explanations
- Add examples or code snippets
- Translate content to other languages

### 3. Suggest Resources
Know a great learning resource?
- Open a Discussion in the [Resources](https://github.com/IsaacZhaoo/aicodingclub/discussions/categories/resources) category
- Include: title, link, description, why it's useful

### 4. Submit Code Changes
Want to improve the website?
- Fork the repository
- Create a feature branch
- Make your changes
- Submit a Pull Request

## 📋 Pull Request Process

1. **Fork & Clone**
   ```bash
   git clone https://github.com/YOUR-USERNAME/aicodingclub.git
   cd aicodingclub
   npm install
   ```

2. **Create a Branch**
   ```bash
   git checkout -b feature/your-feature-name
   # or
   git checkout -b fix/bug-description
   ```

3. **Make Changes**
   - Write clear, concise commit messages
   - Test your changes locally: `npm start`
   - Ensure build works: `npm run build`

4. **Commit & Push**
   ```bash
   git add .
   git commit -m "Add: brief description of changes"
   git push origin feature/your-feature-name
   ```

5. **Open Pull Request**
   - Go to GitHub and open a PR
   - Fill in the PR template
   - Link related issues if any

## 🎨 Code Style

- **TypeScript/JavaScript**: Follow existing code style
- **Markdown**: Use clear headings and lists
- **Commits**: Use conventional commits format
  - `Add:` for new features
  - `Fix:` for bug fixes
  - `Update:` for content changes
  - `Docs:` for documentation

## 📚 Content Guidelines

### Tutorials & Docs
- **Beginner-friendly**: Assume zero prior knowledge
- **Practical**: Include real examples
- **Clear structure**: Use headings, lists, code blocks
- **Accurate**: Test all code examples

### Resources
- **Quality over quantity**: Only recommend truly useful resources
- **Current**: Ensure links are not outdated
- **Diverse**: Include different learning styles (video, text, interactive)

## 💬 Questions?

Please be respectful and constructive. We're all here to learn!
