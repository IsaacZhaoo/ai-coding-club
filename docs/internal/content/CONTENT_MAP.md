## Content Decision Tree

**"I'm interested in learning to code with AI. Where do I start?"**

```
START: Visit aicoding.club
  ↓
Q1: Do you have any coding experience?
  ├─ NO → Continue to Q2
  └─ YES → (This site is for absolute beginners, but continue anyway)
  
Q2: How much time can you commit?
  ├─ "Just 30 seconds to see if this works"
  │   └─→ CSV → Markdown Demo
  │
  ├─ "A few hours to understand concepts"
  │   └─→ Stage 0: Vibecoding (learn by doing)
  │
  ├─ "I want a structured path"
  │   └─→ AI Coding Roadmap (36 weeks)
  │
  └─ "I want to understand how to prompt AI"
      └─→ Prompt Engineering 101 (5 templates)

Q3: After learning Stage 0, are you excited?
  ├─ YES, let's keep going!
  │   └─→ Stage 1: Reality Check (understand limitations)
  │
  └─ I hit a wall / Got confused
      └─→ Tools Comparison (pick better tool)
          OR Prompt Engineering 101 (improve prompts)

Q4: After Stage 1, ready to go deeper?
  ├─ YES, how do I structure projects better?
  │   └─→ Stage 2: Context & Architecture
  │
  └─ I need specific help
      ├─→ [FUTURE] Domain tutorials (web, backend, data)
      ├─→ [FUTURE] Debugging guide
      └─→ [FUTURE] Career guidance
```
