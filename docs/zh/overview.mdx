# AI Coding Club 中文站

欢迎来到 AI Coding Club 中文站!这里是面向中文开发者的 AI 协作编程学习平台。

## 这里有什么?

AI Coding Club 中文站汇集了三大核心内容:

### 1. **站点原有内容** - 基础学习资源

- **AI 手册**: LLM 基础知识、Prompt 工程、AI 工具使用指南
- **清单与工具**: Prompt 清单、开发工具、实用资源汇总
- **社区问答**: 提问交流、经验分享、问题解答
- **实战课程**: 31 节系统化课程,从零基础到实战项目

### 2. **Vibe Coding 实战路线** - AI 协作编程方法论

一套经过实战检验的、系统性的 AI 协作编程方法论,帮助你从想法到产品的完整过程。

**核心内容**:
- 从想法到 PRD: 如何与 AI 一起构思产品需求
- 技术选型与架构: Supabase + TypeScript + Vercel 技术栈深度解析
- 共鸣编程工作流: 上下文管理、AI 规则设定、高效协作工具链
- 工程化与复盘: 测试策略、部署监控、项目复盘方法论

### 3. **LLM 高效推理深度阅读** - 技术深度解读

14 篇论文 + 2 篇博客,构建大模型推理系统的完整知识图谱。

**技术方向**:
- 全局综述 & 技术地图
- 推理引擎实现: vLLM & SGLang
- Roofline 模型 & 硬件视角
- KV Cache & 长上下文优化

## 使用建议

### 对于初学者

1. 先浏览 **AI 手册** 了解基础概念
2. 通过 **实战课程** 系统学习
3. 参考 **清单与工具** 提升效率
4. 在 **社区问答** 中交流讨论

### 对于实践者

1. 学习 **Vibe Coding** 方法论
2. 在实际项目中应用所学
3. 遇到问题时查阅工具清单
4. 分享经验帮助他人

### 对于技术深入者

1. 阅读 **LLM 推理** 系列文章
2. 理解推理系统的技术细节
3. 探索性能优化方向
4. 关注最新技术进展
