# 从想法到 PRD

> 本节内容将基于 vibe.txt 进行重构,敬请期待

## 核心内容预告

### 为什么需要 PRD?

- 模糊的想法无法直接变成代码
- PRD 是你和 AI 的"共同语言"
- 写 PRD 的过程就是思考产品的过程

### 三步写出 PRD

1. **倾倒想法**: 不加过滤地说出你的构思
2. **AI 追问**: 让 AI 帮助你澄清细节
3. **功能梳理**: 整理成结构化的需求文档

### 你将获得

- 一份清晰的产品需求文档
- 对产品边界的明确认知
- 与 AI 高效协作的第一步
