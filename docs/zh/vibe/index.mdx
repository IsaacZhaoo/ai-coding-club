# Vibe Coding 实战路线

> 一套经过实战检验的、系统性的 AI 协作编程方法论

## 📖 什么是 Vibe Coding?

Vibe Coding 是一种全新的开发范式,它不仅仅是让 AI 帮你写代码,而是从根本上重塑整个软件开发流程:

- **从项目管理视角**: 如何构思、规划、执行一个 AI 辅助的项目
- **从架构设计角度**: 如何选择适合 AI 协作的技术栈和架构
- **从开发协作层面**: 如何管理上下文,让 AI 真正理解你的需求

这是一个从 0 到 1,从想法到产品的完整实战路线。

## 🛠️ 技术栈说明

### 本路线使用的技术栈

- **后端**: Supabase (PostgreSQL + 实时数据库 + 认证)
- **前端**: TypeScript + React / Next.js
- **部署**: Vercel
- **AI 工具**: Cursor / Claude Code

### 为什么选择这套栈?

1. **极适合 AI 协作**: 声明式开发,AI 容易理解和生成代码
2. **开发效率高**: Supabase 提供开箱即用的后端服务
3. **成本低**: 有慷慨的免费额度,适合个人项目
4. **生态完善**: 文档齐全,社区活跃

### 如果我用其他技术栈?

没问题!**80% 的方法论是通用的**:

- **Python 开发者**: 核心理念完全适用,工具链略有不同
- **Java 开发者**: 可以应用相同的上下文管理原则
- **前端开发者**: 可以专注于前端部分,后端使用 BaaS 服务
