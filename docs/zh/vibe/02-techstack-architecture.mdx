# 技术选型与架构

> 本节内容将基于 vibe.txt 进行重构,敬请期待

## 核心内容预告

### 推荐技术栈

- **后端**: Supabase (PostgreSQL + 实时数据库 + 认证)
- **前端**: TypeScript + React / Next.js
- **部署**: Vercel
- **AI 工具**: Cursor / Claude Code

### 为什么这套栈适合 AI 协作?

1. **声明式开发**: AI 容易理解和生成
2. **文档完善**: AI 训练数据中包含大量示例
3. **生态完整**: 减少"造轮子",专注业务逻辑

### 其他技术栈的适配

- Python + FastAPI / Django
- Java + Spring Boot
- Go + Gin
