# Phase 2: Essential Skills

Build on your foundation with essential tools and techniques that every developer needs.

## What You'll Learn

- Command line basics for navigating your system
- Git and GitHub for version control and collaboration
- Writing and running tests to verify your code
- Advanced prompting techniques for better AI assistance
- Setting up your IDE with AI tools
- Choosing the right AI coding assistant

## Lessons in This Phase

1. **Command Line Basics** - Navigate like a pro
2. **Git and GitHub 101** - Version control fundamentals
3. **Multi-Turn Mastery** - Real conversations with AI
4. **Advanced Prompting** - Personas, examples, chain-of-thought
5. **Testing Fundamentals** - Write code that works
6. **Debugging Deep Dive** - Advanced troubleshooting
7. **Setting Up Your IDE** - AI tools in your editor
8. **Choosing Your AI Assistant** - Tool comparison guide

## Time Commitment

**8 lessons × 45-60 minutes = ~6-8 hours total**
