# Site Growth: Understand How Your Site Is Found and Used

Launching a website or an online tool changes the questions you need to answer. You now need to know whether people can find a page, where visits come from, and whether visitors complete the task the page was built for.

Site Growth is a short learning path for independent site operators and small teams. It connects search visibility, site acquisition, and task completion without assuming that every traffic change needs a complex SEO diagnosis.

## Start with the measurement map

[Google Search Console vs. GA4: What Each Metric Actually Measures](./search-console-vs-ga4-metrics-map.md) explains four observation points:

1. search appearance;
2. search click;
3. visit source;
4. task completion.

Use it when Search Console, Bing Webmaster Tools, and GA4 show different numbers and you need to decide which dashboard answers your question.
