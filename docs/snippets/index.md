# Script Snippets

These small snippets are starting points for common automation tasks. Use them as examples, then ask your AI assistant to adapt them to your files and workflow.

- **[Data Processing](./data-processing.md)** - Read, clean, merge, and summarize CSV or Excel data.
- **[File Operations](./file-operations.md)** - Rename, move, find, and organize files.
- **[API Requests](./api-request.md)** - Fetch JSON, send requests, and save API responses.

Always test snippets on a copy of your data first.
