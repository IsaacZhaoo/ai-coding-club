# AI Coding Club - Content Repository

This repository contains all the content (documentation, blog posts, tutorials) for [AI Coding Club](https://aicoding.club).

## Structure

```
├── docs/           # Documentation and tutorials
├── blog/           # Blog posts
├── static/img/     # Images and media files
└── i18n/           # Translations (Chinese, etc.)
```

## Contributing

We welcome contributions! Please see our [Contributing Guide](https://github.com/IsaacZhaoo/aiCodingClub/blob/main/docs/internal/contributing/CONTRIBUTING.md) for details.

### Content Guidelines

- Write in clear, beginner-friendly language
- Include practical examples and code snippets
- Test all code examples before submitting
- Add Chinese translations for important content
