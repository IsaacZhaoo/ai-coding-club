# Reproducible Examples

This directory contains source fixtures referenced by AI Coding Club tutorials.
The files are maintained in GitHub so readers can inspect commits, review diffs,
and run the examples locally.

- Keep each example self-contained and covered by its documented test command.
- Commit lockfiles needed to reproduce the verified dependency set.
- Do not commit `node_modules/`, generated output, or downloadable archives.
- Link tutorials to the relevant GitHub directory or tested commit rather than
  copying binary downloads into the website's static assets.
