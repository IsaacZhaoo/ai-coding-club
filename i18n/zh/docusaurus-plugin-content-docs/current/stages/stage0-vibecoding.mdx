# 阶段 0：Vibecoding（氛围编程）

**欢迎来到你的 AI 编程之旅的起点！**

## 什么是 Vibecoding？

Vibecoding 是一种使用 AI 帮助你编程的实践方法，你只需用自然语言描述你想要的功能。它非常适合想要开始构建项目但没有深厚技术知识的初学者。

## Vibecoding 成功技巧

### 从小处开始
从计算器、待办事项列表或基本网站等简单项目开始。不要试图在第一天就构建 Facebook！

### 提示要具体
不要说"做一个网站"，而是尝试"使用 HTML 和 CSS 创建一个简单的个人作品集网站，包含页眉、关于部分和联系表单。"

### 通过修改来学习
获取 AI 生成的代码并尝试修改它。如果你修改颜色、文本或功能会发生什么？这就是你学习的方式！

### 不要害怕错误
错误消息是学习的机会。将它们复制到你的 AI 助手中并询问"如何修复这个错误？"

### 构建让你兴奋的东西
选择你热衷的项目。更多动力 = 更快学习！
