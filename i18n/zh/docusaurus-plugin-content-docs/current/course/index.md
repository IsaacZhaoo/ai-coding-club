# AI编程课程

欢迎来到AI编程俱乐部课程！这个综合课程使用AI编程助手将你从绝对初学者带到可求职的开发者。

课程分为5个递进阶段：

### 🌱 第1阶段：基础（8课时）
开始你的旅程！学习什么是AI编程，与AI进行第一次对话，并构建你的第一个程序。

[开始第1阶段 →](01-foundations/01-welcome.md)

:::info 🔜 第2阶段：核心技能 | Phase 2: Essential Skills（敬请期待）

**Master the fundamental tools and techniques every developer needs.**

**你将学习：**
- 💻 命令行精通
- 🔄 Git & GitHub 工作流
- 🧪 测试策略
- 💡 高级提示技巧

💬 [在 GitHub Discussions 关注更新](https://github.com/IsaacZhaoo/aiCodingClub/discussions)

## 学习方法

本课程遵循独特的"Vibecoding"方法论：
- **对话驱动**：通过与AI助手对话学习
- **实践优先**：从第一天开始构建真实项目
- **初学者友好**：无需先前编程知识
- **AI增强**：学习现代开发者实际工作的方式

## 时间承诺

- **每课时**：30-60分钟
- **整个课程**：约25-30小时
- **推荐进度**：每周3-4课时

## 先决条件

- 一台带互联网连接的计算机
- 好奇心和实验意愿
- 无需先前编程经验
