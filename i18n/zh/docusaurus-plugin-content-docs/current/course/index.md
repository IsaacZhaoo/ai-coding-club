# AI编程课程

欢迎来到AI编程俱乐部课程！这个综合课程使用AI编程助手将你从绝对初学者带到可求职的开发者。

## 课程结构

课程分为5个递进阶段：

### 🌱 第1阶段：基础（8课时）
开始你的旅程！学习什么是AI编程，与AI进行第一次对话，并构建你的第一个程序。

[开始第1阶段 →](./foundations/welcome)

### ⚡ 第2阶段：核心技能（8课时）
掌握每位开发者必备的基础工具和技术。

[开始第2阶段 →](./02-essential-skills)

### 🏗️ 第3阶段：构建项目（7课时）
应用所学技能，从规划到部署构建真实项目。

[开始第3阶段 →](./03-building-projects)

### 🎯 第4阶段：专业化（6课时）
选择你的方向：前端、后端或数据/自动化专业化。

[开始第4阶段 →](./04-specialization)

### 💼 第5阶段：职业发展（2课时）
通过作品集构建和面试准备进入就业市场。

[开始第5阶段 →](./05-career)

## 学习方法

本课程遵循独特的"Vibecoding"方法论：
- **对话驱动**：通过与AI助手对话学习
- **实践优先**：从第一天开始构建真实项目
- **初学者友好**：无需先前编程知识
- **AI增强**：学习现代开发者实际工作的方式

## 时间承诺

- **每课时**：30-60分钟
- **整个课程**：约25-30小时
- **推荐进度**：每周3-4课时

## 先决条件

- 一台带互联网连接的计算机
- 好奇心和实验意愿
- 无需先前编程经验
