# 第4阶段：专业化

选择你的专业化路径并深入到你感兴趣的领域。

## 你将学到什么

- 可用的专业化路径概览
- **前端**：用AI构建现代用户界面
- **后端**：创建API和使用数据库
- **数据/自动化**：Python脚本和数据分析
- 高级重构技术
- 代码审查和协作技能

## 这个阶段的课程

1. **专业化路径** - 选择你的方向
2. **前端专业化** - 现代UI开发
3. **后端专业化** - API和数据库
4. **数据和自动化** - Python提高生产力
5. **重构的艺术** - 改进现有代码
6. **协作和代码审查** - 与他人合作

## 时间承诺

**6课时 × 60-90分钟 = 总共约6-9小时**
