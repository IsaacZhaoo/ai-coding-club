到现在为止，你可能一直在单独的浏览器标签页中与AI互动。这是学习的好方法，但真正的生产力收获来自于将你的AI助手直接带入你的代码编辑器。

将AI集成到你的IDE（集成开发环境）就像将你的副驾驶从乘客座位移到你的驾驶舱。这对工作流程和效率是一个改变游戏的举措。

### 为什么集成？在编辑器中AI的力量

在浏览器和编辑器之间复制和粘贴代码是缓慢的，并打破你的焦点。IDE集成提供更紧密的反馈循环。

1. **自动背景**：最好的AI扩展是背景感知的。他们知道你在哪个文件上工作、你使用的是什么语言，有时甚至知道你项目中的其他文件。这意味着你花更少的时间编写背景大量的提示。
2. **内联建议**：许多工具在你输入时提供自动完成风格的建议。他们可以完成一行代码、建议函数体，甚至根据你刚写的注释编写整个类。
3. **编辑器内聊天**：你可以突出代码块并直接在编辑器中提问。"解释这个正则表达式"、"重构这个函数"或"在这段代码中找到bug"，所有不离开你的文件。
4. **无缝操作**：好的集成允许你用单击应用AI的建议，自动用改进的版本替换你选择的代码。

### 开始：寻找什么

大多数现代代码编辑器都有扩展或插件的市场。开始通常就像搜索"AI"并安装工具一样简单。

以下是一般过程：

1. **打开编辑器的扩展市场**：在VS Code中，它是"扩展"视图。在JetBrains IDE（如WebStorm或PyCharm）中，它位于`设置>插件`下。
2. **搜索一个受欢迎的AI助手**：寻找工具如GitHub Copilot、Codeium或其他在社区中备受推崇的工具。
3. **安装和认证**：你可能需要安装插件，然后用账户登录（例如，你的GitHub账户）。
4. **探索功能**：安装后，在侧边栏中寻找新图标或命令面板中的新命令（`Ctrl+Shift+P`或`Cmd+Shift+P`）。花几分钟学习关键功能，如如何打开聊天面板或触发内联建议。

不用担心立即选择"完美"工具。目的是安装一个并开始体验集成工作流的好处。
