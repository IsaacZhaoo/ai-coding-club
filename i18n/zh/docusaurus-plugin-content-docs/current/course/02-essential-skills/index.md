# 第2阶段：核心技能

以你的基础为基础，学习每个开发者都需要的基础工具和技术。

## 你将学到什么

- 用于导航系统的命令行基础
- Git和GitHub用于版本控制和协作
- 编写和运行测试以验证你的代码
- 用于获得更好AI帮助的高级提示技术
- 使用AI工具设置你的IDE
- 选择正确的AI编程助手

## 这个阶段的课程

1. **命令行基础** - 像专业人士一样导航
2. **Git和GitHub 101** - 版本控制基础
3. **多轮掌控** - 与AI进行真实对话
4. **高级提示工程** - 角色、例子、思路链
5. **测试基础** - 编写有效的代码
6. **调试深潜** - 高级故障排除
7. **设置你的IDE** - 编辑器中的AI工具
8. **选择你的AI助手** - 工具比较指南

## 时间承诺

**8课时 × 45-60分钟 = 总共约6-8小时**
