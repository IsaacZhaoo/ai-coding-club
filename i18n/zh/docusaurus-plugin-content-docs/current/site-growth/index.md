# 小站增长：看懂网站怎样被发现和使用

网站或在线工具上线之后，新的问题会接连出现：页面有没有被人找到，访问从哪里来，用户进入后有没有完成这个页面承载的任务。

小站增长是一条为个人运营者和小团队准备的短学习路径。它把搜索可见性、到站访问和任务完成连在一起，帮助你根据眼前的问题找到正确的数据入口。

## 从指标地图开始

[Google Search Console 和 GA4 分别看什么？从搜索展示到任务完成](./search-console-vs-ga4-metrics-map.md)解释四个观察位置：

1. 搜索展示；
2. 搜索点击；
3. 访问来源；
4. 任务完成。

当 Search Console、Bing Webmaster Tools 和 GA4 给出不同数字时，可以先用这张地图判断应该打开哪个后台。
