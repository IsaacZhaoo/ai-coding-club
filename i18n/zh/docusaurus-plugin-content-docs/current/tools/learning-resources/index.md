## 常见问题

### 初学者应该选哪个 AI 编程工具？

我们建议先用 [ChatGPT](https://chatgpt.com) 学习概念，准备好写代码后再用 [Cursor](/docs/tools/coding-assistants/cursor) 或 [GitHub Copilot](/docs/tools/coding-assistants/github-copilot)。两者都有免费版。详见我们的 [AI 工具对比](/docs/tools/ai-tools-comparison)。

### 零基础能用 AI 学编程吗？

可以。AI 编程工具让编程变得更容易上手。我们的[31课时课程](/docs/course)专为零基础设计，你将从零开始，用 AI 作为编程伙伴，构建真实项目。

### 这些资源真的免费吗？

"免费课程"和"视频教程"中的所有资源完全免费。Cursor 和 GitHub Copilot 等工具有免费版但有使用限制。我们的课程和社区 100% 免费。

### 这个页面多久更新一次？

我们每月审核和更新。资源根据社区反馈和我们自己的测试添加。上次审核：2026年3月。

### 用 AI 学编程应该先学什么语言？

Python 和 JavaScript 是最受欢迎的选择。Python 更适合数据处理、自动化和 AI/ML，JavaScript 更适合 Web 开发。我们的[课程](/docs/course)两者都涉及，AI 工具与所有主流语言都兼容。
