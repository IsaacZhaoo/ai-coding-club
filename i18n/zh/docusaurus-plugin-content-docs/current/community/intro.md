# 社区与支持

欢迎来到AI编程俱乐部社区!这是一个供学习者、开发者和AI爱好者交流、分享和共同成长的空间。

## 💬 获取帮助与提问

### GitHub Discussions
我们的主要社区平台,用于讨论、问答和分享经验。

**即将推出**:我们正在设置GitHub Discussions,以便进行结构化的社区对话。

### GitHub Issues
报告bug、请求新功能或提出技术问题。

🔗 [提交Issue](https://github.com/IsaacZhaoo/aiCodingClub/issues)

## 🤝 如何参与

### 分享你的经验
- 撰写你的AI编程学习之旅
- 分享你发现的技巧和窍门
- 记录你克服的挑战

### 帮助他人
- 回答初学者的问题
- 审查并建议改进内容
- 分享你发现的有用资源

### 贡献内容
- 提交教程或指南
- 将内容翻译成其他语言
- 创建示例和演示项目

## 📖 社区准则

### 互相尊重
- 以友善和尊重对待每个人
- 欢迎新手和初学者
- 提供建设性的反馈

### 保持主题相关
- 保持讨论与AI辅助编程相关
- 分享实用、可操作的建议
- 避免推广性内容

### 给予归属
- 分享他人作品时注明来源
- 感谢有帮助的社区成员
- 分享对你有用的方法

## 成功故事

与社区分享你的成功故事!我们很想听到:
- 你用AI辅助构建的项目
- 你解决的问题
- 你培养的技能
- 你取得的职业进展
